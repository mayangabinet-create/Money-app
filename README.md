# 🎯 קופה — אפליקציה שסופרת כסף עד ליעד

אפליקציה קטנה ואישית: מגדירים מה רוצים לקנות וכמה זה עולה, ואז מוסיפים כל סכום
שנכנס (דמי כיס, משכורת, מתנה). האפליקציה מראה כמה נאסף, כמה נשאר, ומתי לפי הקצב
הנוכחי מגיעים ליעד.

## איך מפעילים

**הכי פשוט:** פותחים את `index.html` בדפדפן (דאבל־קליק). זה הכל — אין התקנה ואין שרת.

**להתקנה בנייד (מומלץ):** מעלים את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify),
נכנסים מהנייד ובוחרים "הוסף למסך הבית". אז זה נפתח כמו אפליקציה אמיתית, גם בלי אינטרנט.

הפעלה מקומית עם שרת (כדי שה־Service Worker יעבוד):

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

## מה יש בפנים

- **טבעת התקדמות** עם הסכום שנאסף, האחוז, וכמה נשאר.
- **הוספה מהירה** — כפתורי 20 / 50 / 100 / 200 / 500 או סכום חופשי, עם הערה מאיפה הכסף.
- **מצב הוצאה** — אם הוצאת מהקופה, מורידים סכום.
- **סטטיסטיקות** — מספר הפקדות, ממוצע להפקדה, קצב שבועי, והערכת תאריך סיום.
- **היסטוריה** עם מחיקה וביטול מחיקה.
- **קונפטי** כשמגיעים ליעד 🎉
- **מצב כהה/בהיר**, ממשק RTL בעברית, מותאם נייד.
- **בחירת מטבע**: ₪ / $ / € / £.

## איפה נשמרים הנתונים

הכל נשמר מקומית בדפדפן (`localStorage`) — שום דבר לא נשלח לשום מקום.
הנתונים שייכים לדפדפן ולמכשיר שבהם השתמשת; ניקוי נתוני הדפדפן ימחק אותם.

## מבנה

| קובץ | תפקיד |
|------|-------|
| `index.html` | כל האפליקציה — HTML, CSS ו־JS בקובץ אחד |
| `manifest.json` | הגדרות התקנה כאפליקציה (PWA) |
| `sw.js` | Service Worker לעבודה במצב לא־מקוון |
